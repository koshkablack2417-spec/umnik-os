# Умник ОС

Android-лаунчер от компании **Умник**. Ставится как обычное приложение, а потом
становится главным экраном телефона: свои обои, часы, свои приложения.

## Что внутри (версия 0.1)

- **Главный экран:** часы, дата, приложения Умника, док (Телефон, Сообщения, Камера, Все приложения).
- **Vexo:** браузер Умника. Открывается Google, есть кнопки «назад», «вперёд», «обновить» и адресная строка.
- **Заметки:** простой блокнот, текст сохраняется сам.
- **Все приложения:** список всего, что установлено на телефоне.

## Как установить на телефон

1. Открой на телефоне страницу **Releases** этого репозитория.
2. В самой верхней сборке скачай файл `umnik-os.apk`.
3. Открой файл и разреши установку из этого источника (Huawei может спросить подтверждение).
4. Нажми кнопку «Домой» и выбери **Умник ОС**, затем «Всегда».
   Если окно не появилось: Настройки → Приложения → Приложения по умолчанию → Главный экран → Умник ОС.

Чтобы вернуть старый рабочий стол, выбери его там же.

## Как собирается APK

При каждом изменении в ветке `main` GitHub Actions сам собирает APK и выкладывает его
в **Releases**. Руками ничего собирать не нужно.
