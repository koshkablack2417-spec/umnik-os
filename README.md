# Умник ОС

Android-лаунчер от компании **Умник**. Ставится как обычное приложение, а потом
становится главным экраном телефона: свои обои, часы, свои приложения.

## Что внутри (версия 0.2)

- **Главный экран:** часы, дата, погода, приложения Умника, поиск Google внизу и док
  (Телефон, Сообщения, Камера, Все приложения).
- **Vexo:** браузер Умника. Открывается Google, есть «назад», «вперёд», «обновить» и адресная строка.
- **Умник Store:** каталог популярных приложений (ВК, MAX, Telegram, игры, банки и другие) с поиском
  и категориями. Установленные приложения открываются, остальные ищутся в RuStore и Google Play.
  Часть приложений помечена «Недоступно» (например, FaceTime и iMessage только для Apple).
- **Умник:** голосовой помощник. Понимает «который час», «открой ВК», «найди …», «погода».
  Если на телефоне нет службы распознавания речи, можно писать команды текстом.
- **Погода:** сейчас и на 5 дней для любого города (сервис Open-Meteo).
- **Umplay:** автомобильный режим с большими кнопками (навигация, музыка, телефон, Умник, погода).
- **Trio:** вход в мессенджер «Трио» (сообщения и видеозвонки). Если приложения Трио нет, предлагает скачать.
- **Настройки:** тема оформления, формат времени, имя, город для погоды, переход в настройки Android.
- **Заметки** и **Все приложения**.

## Как установить на телефон

1. Открой на телефоне страницу **Releases** этого репозитория.
2. В самой верхней сборке скачай файл `umnik-os.apk`.
3. Открой файл и разреши установку из этого источника (Huawei может спросить подтверждение).
4. Нажми кнопку «Домой» и выбери **Умник ОС**, затем «Всегда».
   Если окно не появилось: Настройки → Приложения → Приложения по умолчанию → Главный экран → Умник ОС.

Чтобы вернуть старый рабочий стол, выбери его там же.

## Как собирается APK

При каждом изменении в ветке `main` GitHub Actions сам собирает APK и выкладывает его
в **Releases**. Руками ничего собирать не нужно.
